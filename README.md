# Ao Sun's homepage

**[aosunmath.github.io](https://aosunmath.github.io/)**

A minimal personal homepage, currently linking to the **[Stack Project of Geometric Measure Theory and Variational Problems](https://aosunmath.github.io/GMT-stack/)**.

Edit `index.html` to expand the homepage. GitHub Pages publishes the root of the `main` branch; `.nojekyll` preserves the plain static HTML.

For a local preview:

```sh
python3 -m http.server 8001
```

Then open [localhost:8001](http://localhost:8001/).
